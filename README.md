# DSH-grill-plan-act-button
为DeepseekHarness输入栏添加按钮控制DSH切换plan/grill plan/limit/act模式，让用户便利地使用plan/act工作流，并控制DSH工作在合适的复杂程度。

Add buttons to the input bar of DeepseekHarness to control DSH to switch between plan/drill plan/limit/act modes, allowing users to conveniently use the plan/act workflow and control DSH to work at the appropriate level of complexity.

模式介绍：
plan：计划模式，用于制定执行计划、对齐用户需求
grill plan：在计划模式的基础上内置经典技能grill me skill，用于进行详尽的计划。
act：原版的DSH的标准模式，可以使DSH不受此插件的影响按照原本的方式工作，从plan/grill plan中的执行按钮中跳转过来时，可以执行它们的计划。
limit（bata）：用于限制DSH过度反应，阻止“雷霆大寻思”。在进行简单问答时使用，防止大肥鱼浪费你的token。
