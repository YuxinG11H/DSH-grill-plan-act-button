# DSH 四态模式轮盘

给 DeepSeek Harness 输入栏加一个模式切换按钮：**先规划、深入追问、直接执行，或简单回答**，让 DSH 按任务需要工作，而不是逢事就“雷霆大寻思”。

![模式轮盘展开效果](docs/images/轮盘.png)

## 四种工作方式

| 模式 | 标签 | 用途 |
|---|---|---|
| 标准／执行 | BASE | 不注入额外模式提示词，不增加本插件的工具限制，尽量保持原生 DSH 行为。同时作为 ACT 模式，通过执行按钮接续 PLAN／GRILL 的计划。 |
| 计划 | PLAN | 先只读了解现状、确认需求，再交付完整方案，等待你决定是否执行。用于制定执行计划、对齐用户需求。 |
| 审问／深度计划 | GRILL | 在计划模式基础上内置经典 grilling 的连续追问流程，按决策依赖逐轮问清选择，适合复杂需求和详尽计划。 |
| 限制（Beta） | LIMIT | 用于简单问答，限制文件修改、命令和子任务，减少过度反应与不必要的复杂化，尽量避免大肥鱼浪费你的 Token。 |

**LIMIT 仍在试验。** “雷霆大寻思”属于偶发行为，难以稳定复现，目前针对这一现象的测试仍然不足；该模式不能保证阻止所有长推理或一定节省 Token。

PLAN／GRILL 不限于写代码，生活决策、资料分析、写作也应先对齐需求、规划行动，而不是直接交付成品。PLAN 使用本插件的提示词与工具限制，不是直接启用官方 plan-mode。

## 怎么用

- **点击头像或模式名**展开轮盘，点击角色切换模式。
- **原地连续点击两次**可以切回 BASE。
- **右键头像**打开设置，可调整退出延迟、标签语言及模式名显示。
- **各会话独立**：在一个会话切模式，不改变另一个会话。任务处理中切换，下一轮生效。

### 先计划，再执行

切到 PLAN 或 GRILL，与 AI 对齐需求。完整计划提交并正常结束后，模式名位置出现 **蓝色 ▶**；点击后切到 BASE 执行。

追加需求或开始新一轮后，旧计划按钮立即失效，直到新的完整计划形成。旧资格不会在重启后自动恢复。

### 没有蓝色按钮，也能手动继续

如果模型漏掉计划提交步骤，你可以**手动从 PLAN／GRILL 切到 BASE**。当前轮次结束后，会出现 **蓝黑色 ▶「手动继续」**。

它不代表已有完整计划，更不是系统权限批准。悬停或聚焦按钮会给出风险提醒，请确认上下文和需求后再点，不要随意点击。

两种按钮都会发送：

> 现在请直接执行任务。

发送成功后收起，失败只显示错误，不自动重发。手动按钮会在新消息、新轮次、再次切模式或刷新后清除；正常蓝色按钮执行后的自动切换，不会再产生手动按钮。

### 问题卡片按模式分别控制

右键设置中，**勾选表示禁用**：

| 设置 | 默认值 |
|---|---|
| 禁用 PLAN 问题卡片 | ☑ 勾选，必要问题用编号文字提出 |
| 禁用 GRILL 问题卡片 | ☐ 不勾选，连续追问使用 Question Card |

设置从下一次模型请求生效。禁用卡片不等于跳过必要澄清，启用卡片也不意味着必须凑问题。

## 安装

在官方 **“添加插件”** 窗口输入 GitHub 安装规格：

```text
github:YuxinG11H/DSH-grill-plan-act-button
```

这会安装默认分支的当前代码。发布对应标签后，可在末尾添加 `#v0.2.0-rc.2` 固定版本。

国内用户若连接 GitHub 不稳定，可以下载完整资源包并解压，在同一窗口填写**直接包含 `package.json` 的文件夹绝对路径**。安装为本地目录链接时，不要移动或删除该目录。

安装／更新后，按宿主提示**完全退出 DSH（包括托盘）再打开**。目前尚未发布 npm，不要直接用裸包名查找安装。

## 注意事项

- 当前为 **v0.2.0-rc.2 预发布版**，主要针对 DSH 桌面版 0.2.0-rc.2 开发；其他版本和 Web 端尚未完整验收。
- 插件的工具限制不是安全沙箱，两种执行按钮都不会绕过 DSH 自带的权限与审批。
- 蓝色按钮依赖 AI 显式提交计划，不按回答字数猜测完成；没有按钮时可查看头像的原生提示。
- 本插件不需要额外 API Key，也不负责修复其他 HTML 渲染插件。
