# DSH-grill-plan-act-button
为DeepseekHarness输入栏添加按钮控制DSH切换plan/grill plan/limit/act模式，让用户便利地使用plan/act工作流，并控制DSH工作在合适的复杂程度。Add buttons to the input bar of DeepseekHarness to control DSH to switch between plan/drill plan/limit/act modes, allowing users to conveniently use the plan/act workflow and control DSH to work at the appropriate level of complexity.
